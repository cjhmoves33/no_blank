# 레킹볼 타격

레킹볼 위에서 주 버튼을 누르는 순간 효과음이 나고, 공은 맞은 자리의 반대쪽으로 밀려 흔들리다가 잦아듭니다. 레킹볼에서 시작한 드래그는 카메라를 돌리지 않습니다. 사슬은 칠 수 없어서, 사슬에서 시작한 드래그는 배경을 끌 때처럼 카메라를 돌립니다.

## Sub-features

- `strike-sound`: 치는 순간 효과음이 납니다. 버튼을 놓을 때는 나지 않습니다.
- `strike-push`: 옆을 치면 반대쪽 옆으로, 가운데를 치면 뒤로 밀리고, 마개는 늘 매단 지점을 봅니다.
- `strike-lift`: 아래 가장자리를 치면 공이 들리고, 사슬이 느슨해져 옆으로 휘었다가 다시 팽팽해집니다.
- `swing-fades`: 흔들림은 10초쯤 지나면 거의 멈춥니다.
- `strike-no-orbit`: 레킹볼에서 시작해 끌어도 카메라는 그대로입니다.
- `chain-orbits`: 사슬에서 시작해 끌면 소리 없이 카메라가 돕니다.

## How to get to it (user POV)

- 화면 가운데의 레킹볼을 마우스 왼쪽 버튼으로 누릅니다.
- 레킹볼의 오른쪽 가장자리나 아래 가장자리를 누릅니다.
- 레킹볼을 누른 채 옆으로 끕니다.
- 레킹볼 위의 사슬을 누른 채 옆으로 끕니다.

## Driving it with verify.mjs

Preconditions:

- 증명할 빌드가 준비되어 있고 `doctor` 가 통과합니다.

- **타격.** 레킹볼을 칩니다. `node $V shoot <이름> --views home,struck --out <폴더>` 를 실행합니다. `struck.json` 의 `audioPeak` 가 0.2 이상이고(지금 효과음의 설계 진폭은 0.25, 측정값은 0.239), `home.json` 의 `audioPeak` 는 0 입니다.
- **옆을 친 흔들림.** 공의 오른쪽 가장자리를 칩니다. `node $V shoot <이름> --motion --views home,struck-side-0.2s,struck-side-0.6s,struck-side-1.5s --out <폴더>` 를 실행합니다. 세 장에서 공이 왼쪽 뒤로 밀렸다가 돌아오는 중이고, 마개가 사슬 쪽으로 기울어 있습니다. 실제로 찍히는 시각은 기다린 시간보다 10프레임쯤 늦습니다.
- **아래를 친 들림.** `struck-under` 는 아래 가장자리를 칩니다. 공은 5 cm 쯤 들렸다가 0.2초쯤 뒤에 떨어지므로, 이 스크립트가 찍는 시각에는 이미 떨어져 있습니다(2026-11-22 확인). 들림과 느슨한 사슬은 `swing.test.ts` 가 확인합니다. 휜 사슬을 눈으로 보려면 `normal` 의 `gravity` 를 1 로 낮춘 빌드를 따로 준비해 `--motion --views struck-under` 로 찍고, 그 빌드는 커밋하지 않습니다.
- **레킹볼에서 시작한 드래그.** 레킹볼을 누른 채 끌고, 포인터를 배경으로 옮겨 2초 기다립니다. `node $V shoot <이름> --views home,ball-drag --out <폴더>` 다음에 `node $V diff <폴더>/home.png <폴더>/ball-drag.png` 를 실행합니다. 바뀐 픽셀이 0 개이고, `ball-drag.json` 의 `audioPeak` 는 0.2 이상입니다. 소리가 났고 공도 밀렸지만, 카메라는 돌지 않았고 공은 2초 안에 제자리로 돌아왔다는 뜻입니다. 동작 줄이기를 켠 기본 설정에서만 0 개이고, `--motion` 에서는 공이 아직 흔들리고 있습니다.
- **사슬에서 시작한 드래그.** 사슬을 누른 채 끕니다. `node $V shoot <이름> --views home,chain-drag --out <폴더>` 다음에 `diff` 를 실행합니다. 바뀐 픽셀이 화면 대부분이고(2026-11-22 측정 85%), `chain-drag.json` 의 `audioPeak` 는 0 입니다.

## Gotchas

- 사슬은 처음 카메라 위치에서 폭이 10 px 정도입니다(2026-11-22 측정, 높이 120 px 에서 x 635~645). 처음 카메라 위치나 사슬 굵기를 바꾸면 `ON_CHAIN` 이 배경을 누를 수 있고, 그래도 카메라는 돌므로 `chain-drag` 가 통과해 버립니다. 이런 변경 뒤에는 `home.png` 의 `ON_CHAIN` 자리에 사슬이 있는지 먼저 봅니다.
- `audioPeak` 는 페이지가 만든 AudioContext 의 출력에 분석기를 덧붙여 잰 값입니다. 스피커로 실제 소리가 나는지는 사용자만 확인할 수 있습니다.
- 소리의 모양(음색, 길이)은 사용자가 귀로 판단합니다. 진폭이 같다고 같은 소리라고 보고하지 않습니다.
