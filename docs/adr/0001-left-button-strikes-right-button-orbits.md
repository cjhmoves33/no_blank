# 왼쪽 버튼은 타격, 오른쪽 버튼은 시점 돌리기

3D 장면은 보통 왼쪽 버튼으로 끌어서 카메라를 돌리지만, 이 앱은 왼쪽 버튼을 타격에만 쓰고 시점은 오른쪽 버튼으로 끌어서 돌립니다. 레킹볼 밖에서 왼쪽 버튼을 누른 채 레킹볼을 지나가게 끄는 휘두르기를 넣으려면 왼쪽 끌기가 비어 있어야 하기 때문입니다. 휘두르기가 있어야 훅과 어퍼컷을 끄는 방향과 속도로 표현할 수 있습니다. 그 대신 UI 없이는 시점을 돌리는 법과 휘두르기를 알아채기 어렵고, 트랙패드에서는 오른쪽 버튼으로 끌기가 불편하다는 비용을 받아들였습니다.

## Considered Options

- 왼쪽 끌기로 시점을 돌리고 타격은 잽만 둡니다(이전 방식). 위로 치려면 레킹볼 아래쪽의 좁은 가장자리를 정확히 눌러야 하고, 타격 세기를 사용자가 조절할 방법이 없습니다.

## Consequences

- 효과음은 누르는 순간이 아니라 타격하는 순간에 납니다. 잽은 누르는 순간이 타격이고, 휘두르기는 커서가 레킹볼에 들어가는 순간이 타격입니다. 버튼을 놓을 때 소리를 내지 않는다는 이전 결정의 취지는 그대로입니다.
- 나중에 UI 를 둘지 정할 때, 시점 돌리기와 휘두르기를 알려 줄 방법을 함께 정합니다.
